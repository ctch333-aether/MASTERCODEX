# AETHER Brand Assets - Claude Integration Guide

## Quick Reference

When using these assets with Claude, you can:

### 1. Query Assets by Category
```
"Show me all assets in the logos category"
→ Claude reads manifest.json and lists: rx-lo...
```

### 2. Get Asset Path
```
"What's the path for the MJ character asset?"
→ Claude finds: characters/mj-character.webp (or similar)
```

### 3. Integrate into HTML
```
"Add the AETHER logo to this webpage header"
→ Claude uses manifest to find the correct asset and generate proper HTML
```
